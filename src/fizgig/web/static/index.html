Generate captions
Caption All writes a caption for each picture (and clip) with the model above. Static gives every file just the trigger word. The model stays loaded for quick re-captions; Unload frees its memory (it unloads itself before a run starts).
Caption every song
Gives every song the same caption: the trigger word, then the words every song shares (genre, instruments, mood).
Words every song shares:
Bilingual (English + Chinese)
Adds a Chinese translation to each caption (not songs' lyrics), as "english - chinese", keeping the trigger word first. Uses Helsinki-NLP/opus-mt-en-zh (about 300 MB, downloaded the first time).
Find & Replace
Across every .txt caption in the training folder (not songs' .lyrics.txt), ignoring upper and lower case. Preview shows each change first; nothing is written until Replace.
