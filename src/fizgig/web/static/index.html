Every photo is resized and saved as PNG, plus a zoomed-in copy of the face saved beside it: more detail shots for better likeness. 💡 Works best on high-res originals: if your photos are already shrunk to training size, the face close-ups come out soft. Start from the biggest versions you have.
Just resize and convert to PNG. Use for styles, objects, or already-cropped sets.
Keep only the cropped face from each photo: the full shot is not kept.
Target megapixels: MP (larger images shrink to fit; smaller are left alone)
Face: Padding: % around the face
Face detection isn't installed on the Fizgig computer: run install_fizgig.py there to add it. Resize only still works.
Sizing is by target area (megapixels), not longest side: this matches how training buckets your images, so prepping costs you no resolution. Aspect ratio is kept; nothing is cropped.

Final step: Look Consistency Filter (faces)

            
Run this last, after every other prep stage: it scores the finished training
              folder. Pick three baseline pictures that nail the look you want; every picture's face is scored against
              all three and averaged (ArcFace similarity), so no one photo's angle, expression or light sets the bar.
              It finds pictures that drifted off-look, the near-misses a loss curve can't see. Click pictures to mark
              them, or let Auto-Suggest flag the outliers, then move the marked ones out in one go (to an
              excluded_by_look subfolder; nothing is deleted). The scores are saved with the dataset, so low scorers
              you keep can ease in with the Training tab's "Warm up look outliers".

            

              

                
                
                
              

              
Each score is the average similarity to your 3 baselines. The
                same person typically lands at 30–70%, the baselines included (each is scored against the other two
                as well as itself).

What to measure

            
Find out what each block of the LoRA does: it renders the LoRA, then again with each block
              group switched off, and reports how much each changes the picture, carries the likeness and causes bleed
              (other people starting to look like your subject). Weights only is instant and shows how much rank the LoRA
              really uses.

Log in

      

        
The web UI password. It was set in the desktop app's Preferences > Web UI (or in
          prefs.json). On a RunPod pod it is the pod's VNC_PASSWORD, the same one as its remote desktop; if you didn't
          set one, it is printed in the pod's logs. No user name is needed.
